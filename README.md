# ChatPDF de Convenios Colectivos

Aplicación web desarrollada con Streamlit y LangChain para consultar convenios colectivos laborales (archivos PDF) mediante Inteligencia Artificial (RAG), diseñada para gestorías.

## Cómo desplegar en Streamlit Community Cloud

1. Crea una cuenta en [GitHub](https://github.com/).
2. Crea un nuevo repositorio (recomendado: privado).
3. Sube estos archivos (`app.py`, `requirements.txt`, `.gitignore`, `README.md`) al repositorio.
4. Entra en [Streamlit Community Cloud](https://share.streamlit.io/).
5. Haz clic en "New app".
6. Conecta tu cuenta de GitHub y selecciona el repositorio que acabas de crear.
7. Asegúrate de que "Main file path" dice `app.py`.
8. Haz clic en "Deploy!". En un par de minutos tendrás tu enlace web funcionando.
